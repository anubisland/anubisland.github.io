## 📱 التثبيت كتطبيق مستقل (PWA) على الموبايل والتابلت
يدعم هذا التطبيق تقنية **Progressive Web App (PWA)** بالكامل:
1. افتح الرابط في متصفح **Google Chrome** أو **Safari**.
2. اضغط على خيارات المتصفح (الثلاث نقاط أو زر المشاركة).
3. اختر **"تثبيت التطبيق" (Install App)** أو **"إضافة إلى الشاشة الرئيسية" (Add to Home Screen)**.
4. سينزل التطبيق بأيقونته الملكية المعتمدة ويعمل بكامل طاقته حتى بدون اتصال بالإنترنت (Offline Mode).

## 📖 أمهات كتب التحقيق المعتمدة
- **البرهان في متشابه القرآن** - الإمام الكرماني
- **درة التنزيل وغرة التأويل** - الإمام الخطيب الإسكافي
- **ملاك التأويل** - الإمام ابن الزبير الغرناطي
- **هداية المرتاب وغاية الحفاظ والطلاب** - الإمام علم الدين السخاوي
- **كشف المعاني في متشابه المثاني** - الإمام ابن جماعة الكناني
